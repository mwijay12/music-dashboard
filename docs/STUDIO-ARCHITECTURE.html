Timbre Studio — vifaa vitatu, kazi moja

Plan ya series: PC yako (Ryzen 5 · 16 GB) inakuwa mikono, n8n kwenye VPS inakuwa akili na ratiba, Vercel inakuwa dirisha la kuona kila kitu. Muziki ndio niche ya kwanza; magari (restoration) yanapanda juu ya reli zile zile baadaye bila kubadilisha kitu cha msingi.

1Nani anafanya nini

PC yako — mikono

Ryzen 5 · 16 GB RAM · iGPU 490 MB · Windows
  • ffmpeg: kukata, kuunganisha, kupima sauti, 1080p render
  • Kupanga thumbnails, kutengeneza mafaili ya kupost
  • Hifadhi ya nyimbo/video zote (archive)
  • Inasubiri kazi kwa kupiga simu nje, haifungui mlango

VPS + n8n — akili

Ipo tayari · haina GPU lakini haihitaji
  • Ratiba: kila siku saa 06:00 → “tafuta keywords mpya”
  • Queue ya kazi + retries + log ya kila jaribio
  • Kitufe cha idhini (Telegram): “Post hii?” kabla ya upload
  • YouTube node: upload + publishAt (kupanga saa)

Vercel — dirisha

Ipo tayari (timbre-puce.vercel.app)
  • Dashboard: plan, queue, kilichopost, kilichofanya kazi
  • Research ya keyless (autocomplete + RSS)
  • PDF ya wiki kwa sponsor / media team
  • Haihusiki na kazi nzito — inaonyesha tu

4Usalama: PC haifungui mlango kamwe

Jinsi inavyofanya kazi

  • Worker inauliza n8n kila sekunde 30: “kazi?”
  • n8n inajibu kazi au 204 (hakuna)
  • PC inafanya kazi, inarudisha matokeo
  • Token moja x-timbre-token kila upande

Hakuna port forwarding, hakuna TLS cert ya Windows, hakuna IP ya nyumbani inayojulikana.

Kama kitu kimezimwa

  • PC imelala: kazi zinasubiri queue — hakuna kitu kinavunjika
  • VPS imezimwa: hakuna kupost; PC inarudia jaribio
  • Vercel imezimwa: dashboard haionekani; pipeline inaendelea
  • YouTube key imeisha quota: upload inasubiri siku inayofuata (1,600 ya 10,000)

5Series — kila phase ina kipimo cha “imekamilika”

0

Msingi — leo, dakika 20

Install ffmpeg kwenye PC. Endesha node worker/agent.mjs --self-test. Weka studio/research.json na seeds zako + channel 5 za washindani.

Imekamilika kama: self-test inaonyesha ✓ ffmpeg na ✓ ffprobe.
1

Handshake — PC inajibu n8n

Workflow moja n8n: Webhook → IF token → Respond: job “echo”. Worker inaendesha --once na inarudisha jina la PC + RAM + node version.

Imekamilika kama: n8n inaonyesha execution yenye host, memoryGb: 16.
2

Kazi halisi — render ya kwanza

Weka mp3 + picha kwenye folda. n8n inatuma job render; PC inarudisha mp4 + ukubwa wa faili. Kisha job concat kwa mix ya dakika 60.

Imekamilika kama: mp4 ya dakika 5 iko kwenye diski, ffprobe inaonyesha h264 + aac.
3

Idhini + upload + kupanga saa

Telegram inauliza; n8n YouTube node ina-upload private na publishAt = slot iliyopendekezwa na research (mfano Ijumaa 18:00 EAT). AI disclosure toggle = ON.

Imekamilika kama: video inaonekana YouTube Studio ikiwa “Scheduled”, sio “Public”.
4

Kujifunza — data inarudi

Sync ya kila siku: views, watch time, title ipi ilishinda. Report ya Jumatatu inatoa uamuzi mmoja.

Imekamilika kama: PDF ina ukurasa wa channel: post 3, views, slot bora, na plan ya wiki ijayo.
5

Niche ya pili — magari, reli zile zile

Badilisha pack pekee (studio/prompt-pack.json → pack ya restoration): same queue, same PC, same approval. Kinachobadilika ni prompt na thumbnail template, sio mfumo.

Imekamilika kama: video ya gari inapita pipeline ile ile bila mstari mmoja wa code mpya.
