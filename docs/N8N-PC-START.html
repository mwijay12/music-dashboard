TIMBRE STUDIO / PHASE 1

Jaribio la kwanza: n8n ↔ PC

Hili ni jaribio la mawasiliano tu. Halitengenezi video, haliposti YouTube, na halisomi au ku-update planner ya Timbre.

Mt flow:

PC inauliza n8n ya VPS kama kuna kazi → n8n inarudisha echo → PC inafanya jaribio → PC inatuma majibu n8n. Timbre planner kwa sasa inahifadhi drafts kwenye browser pekee; kuunganisha dashboard na n8n ni hatua inayofuata, si kitu kilichokwishaunganishwa.

Usalama kwanza

Import workflow ikiwa inactive. Weka Header Auth kwenye webhook zote mbili kabla ya ku-activate. Usipeane token kwenye chat au Git. n8n inaweza kuhifadhi request headers, ikiwemo token, kwenye execution history: zuia watu wasiostahili kufikia n8n, punguza/ondoa execution data baada ya jaribio, na badili token ikiwa imeonekana kwa mtu asiyehusika. Tumia HTTPS tu.

1. Andaa PC

  1. Hakikisha Node.js 18+ ipo kwenye Windows. Unahitaji folder la repository lenye worker/agent.mjs kwenye PC yako; kama halipo, pakua checkout ya branch ya kazi kutoka GitHub. Fungua PowerShell ndani ya folder hilo.
  2. Tengeneza token mpya kwenye PowerShell. Amri hii inaiweka kwenye environment ya dirisha hilo na kuikopi kwenye clipboard bila kuichapisha:
$env:TIMBRE_WORKER_TOKEN = node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
Set-Clipboard -Value $env:TIMBRE_WORKER_TOKEN

Token itapotea kwenye dirisha hili ukifunga PowerShell. Hifadhi salama mahali pako pa siri ikiwa utaihitaji tena; usiandike token kwenye file la mradi.

2. Weka workflow kwenye VPS

  1. Fungua n8n yako, kisha import file n8n/pc-handshake.json kutoka repository. Iache inactive wakati wa setup.
  2. Fungua kila webhook: PC asks for a job na PC reports result. Hakikisha Authentication ni Header auth. Tengeneza/chagua credential moja ya Header Auth: header name x-timbre-token, value bandika token kutoka clipboard. Chagua credential hiyo kwenye nodes zote mbili. Usibandike token kwenye workflow JSON.
  3. Save na activate workflow. Tumia production URLs, si test URLs. Hakikisha n8n inazalisha URLs zenye host yako na HTTPS. n8n version/UI inaweza kutofautiana; rekebisha node settings ikiwa import yako inahitaji hivyo.

3. Pima mara moja

Katika dirisha lilelile la PowerShell (na ukiwa kwenye root ya repo):

node worker/agent.mjs --url https://mwijay.duckdns.org/webhook/timbre-handshake/jobs --worker mwijay-pc --once

Ukiona echo → ok, PC imepata kazi na kuripoti majibu kwa n8n. Angalia execution ya PC reports result; body inapaswa kuwa na ok: true na ujumbe Hello from n8n. Jaribu token isiyo sahihi pia: webhook inapaswa kukataa, si kutoa kazi. Ikiwa haikatai, deactivate mara moja na rekebisha auth.

Usitumie --loop kwa jaribio hili.

Workflow hii inarudisha echo kila inapoombwa; si queue. Baada ya jaribio, deactivate workflow na futa execution data yenye headers. Usitumie kazi za render hadi njia halisi ya queue, uthibitishaji na ulinzi wa faili ziwe zimeandaliwa.

Kinachofuata

Queue yenye kudumu na kuzuia kazi kuchukuliwa mara mbili; kuunganisha Timbre kwa API salama; kisha kuhamisha media kati ya PC na VPS/storage na kuweka YouTube OAuth na approval. Filename ya output kwenye PC peke yake haitoshi kwa VPS ku-upload: faili lazima ipatikane kwenye storage inayofikika kwa njia salama.

Kuhusu mfano wako wa YouTube: node ya Get channel ni mwanzo mzuri wa kuthibitisha OAuth. Text uliyotuma ina type iliyogeuzwa kuwa Markdown link; ikiwa una-import kama JSON, inapaswa kuwa string halisi n8n-nodes-base.youTube, si URL ya link.
